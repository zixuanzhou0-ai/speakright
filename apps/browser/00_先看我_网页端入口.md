# 先看我：Speak Right 网页端入口

如果你只是想使用 Speak Right 网页端，不需要理解这个文件夹里的所有源码。

## 最简单的使用方式

Windows 用户：

1. 双击 `01_双击启动网页端.bat`。
2. 等待命令窗口显示启动成功。
3. 浏览器会自动打开 Speak Right。
4. 如果没有自动打开，双击 `02_打开网页端.url`。
5. 使用过程中不要关闭命令窗口。

网页地址通常是：

```text
http://127.0.0.1:4173/
```

如果 4173 被占用，启动脚本会自动尝试 4174、4175 等端口，并把实际地址显示在窗口里。

## 不要点哪里

不要直接双击这些东西：

- `out/index.html`
- `src/`
- `public/`
- `package.json`

原因：Speak Right 要使用麦克风、录音、API 评分和本地资源服务。直接打开 HTML 文件会绕过浏览器需要的本机服务，容易出现录音失败、页面空白或 API 不工作。

## 启动后第一件事

进入网页后，先打开“设置”：

```text
/settings
```

按顺序配置：

1. Azure Speech：真实发音评分。
2. ElevenLabs：标准示范朗读。
3. LLM：中文 AI 教练反馈。
4. 麦克风权限：浏览器弹窗时点击允许。

## 怎么确认已经能用

完成设置后：

1. 打开“自由练习”。
2. 输入一句短句，例如 `hello`。
3. 选择正确麦克风。
4. 点击录音。
5. 停止录音并提交评分。
6. 页面出现总分、准确度、流利度和中文反馈，就说明已经可用。

## 如果启动失败

| 现象 | 处理方式 |
| --- | --- |
| 提示找不到 Node.js | 安装 Node.js LTS 后重新双击启动脚本。 |
| 浏览器打不开 | 手动打开启动窗口里显示的地址。 |
| 端口被占用 | 启动脚本会尝试 4173 到 4178；看窗口里显示的实际地址。 |
| 麦克风没声音 | 到 Chrome 地址栏左侧权限里允许麦克风，并在页面选择正确输入设备。 |
| 没有评分 | 检查 Azure Speech Key 和 Region 是否填写正确。 |

## 给 macOS / Linux 用户

如果文件夹里已经有 `out/`，打开终端，进入这个文件夹，运行：

```bash
node scripts/serve-static.mjs
```

如果没有 `out/`，先运行：

```bash
npm install
npm run build
node scripts/serve-static.mjs
```

然后打开终端里显示的本地地址。
