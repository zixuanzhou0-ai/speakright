# License index

`LICENSE` at the repository root contains the full MIT License for SpeakRight
source code and source-code documentation.

Bundled third-party media remains under its own license or written permission.
The machine-readable source of truth is
`docs/assets/asset-rights-registry.json`; attribution details are summarized in
`THIRD_PARTY_NOTICES.md`.

Canonical public license texts used by individual assets:

- Microsoft Fluent Emoji MIT license (included offline):
  [`MICROSOFT-FLUENT-EMOJI-MIT.txt`](MICROSOFT-FLUENT-EMOJI-MIT.txt)
- Creative Commons Attribution-ShareAlike 3.0 Unported:
  https://creativecommons.org/licenses/by-sa/3.0/legalcode
- Creative Commons Attribution-ShareAlike 4.0 International:
  https://creativecommons.org/licenses/by-sa/4.0/legalcode
- Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 International:
  https://creativecommons.org/licenses/by-nc-nd/4.0/legalcode

`LicenseRef-*` values in the registry refer to a separate written permission or
provider-output boundary. The corresponding private documents are held by the
maintainer and are identified publicly only by a non-sensitive `evidenceRef`.
