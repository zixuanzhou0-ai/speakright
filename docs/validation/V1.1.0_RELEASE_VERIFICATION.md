## User-facing release boundaries

- The Browser Stable contract is a downloadable static build and source
  release. Users serve it on localhost or HTTPS and bring their own provider
  credentials. SpeakRight does not operate a hosted SaaS account or first-party
  recording backend.
- The Desktop Preview contract is unsigned. Windows SmartScreen may show an
  unknown-publisher warning. Users should not bypass antivirus or organizational
  policy; they can build from source or wait for a future signed Desktop Stable
  channel.
- Numeric production scores come from user-configured Azure Speech. Deterministic
  screenshots and test fixtures are labelled example data and cannot be reported
  as live learner scores.
- Hermes/xAI, Vertex AI, ElevenLabs, Azure, dictionary, and LLM availability,
  billing, quotas, and provider retention remain external-service boundaries.
- Routine release validation makes no paid TTS or live Azure scoring call.
