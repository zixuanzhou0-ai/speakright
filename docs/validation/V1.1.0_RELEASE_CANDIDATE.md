## Security triage and dependency boundary

The CodeQL baseline on public merge commit
`feb455dc86fd717fb5f55a064d2a752c3173067e` contained 65 alerts. Static review
found no confirmed cross-boundary vulnerability in the reviewed Browser Stable
or Windows Desktop Preview boundary. The conclusion is revision-specific:
alert dismissal state alone is not evidence, and the final release commit must
receive a fresh hosted scan.

The Tauri update includes the upstream origin-confusion fix even though the
current Desktop does not intentionally load remote pages in its WebView.
`serde_with` and the updatable `rand` branches are also advanced. The remaining
`rand 0.7.3` instance is confined to a Tauri-related build chain; `glib 0.18.5`
is absent from the Windows target graph and belongs to the currently unsupported
Linux Desktop graph. Both exceptions are owned by `@zixuanzhou0-ai`, expire no
later than 2026-11-30, and expire immediately if their documented reachability,
severity, or supported-platform assumptions change. See the public
[code-scanning triage record](../security/CODE_SCANNING_TRIAGE_V1.1.0.md) for
the complete alert mapping and release-blocking conditions.

## Evidence and claim limits

- Screenshot and demo fixtures are labelled example data and make no live paid
  TTS or Azure scoring call.
- Automated, synthetic, and maintainer sessions are not counted toward the
  maintainer-reported offline testing. The maintainer reports 20 offline testers;
  [`USER_TESTING_SUMMARY.md`](USER_TESTING_SUMMARY.md) labels that statement as
  not independently audited and publishes no task-result or learning-outcome
  metric. Participant-level proof and additional study detail are not release or
  application prerequisites.
- American English is the stable learning baseline. Spanish, French, and
  Russian remain experimental.
- Numeric production scores come from the user's Azure service; configured LLMs
  explain evidence and do not create the numeric score.
- The Desktop Preview is unsigned. The bare EXE and NSIS setup may be published
  only with their warning, checksums, SBOMs, and validation reports. MSI is not
  a v1.1.0 public artifact.
- The reviewed NSIS preflight has a narrow process-name check-to-launch timing
  window; the release workflow therefore runs the mutation only on a fresh,
  isolated GitHub-hosted Windows runner.
